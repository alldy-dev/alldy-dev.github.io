# Allan Dymitri — Personal Portfolio

My personal portfolio website, built from scratch with **vanilla HTML, CSS and JavaScript** (no frameworks).

🔗 **Live site:** https://alldy-dev.github.io

## Features

- **Responsive layout** (mobile-first), for mobile and desktop
- **Mobile menu** that opens and closes with JavaScript
- **Light and dark theme**, saved in the browser with `localStorage`
- **3 languages** (Portuguese, Spanish and English), switched with JavaScript and saved in the browser
- **CV download** in the selected language

## Technologies

- HTML5 (semantic structure)
- CSS3 (Flexbox, CSS variables, media queries)
- JavaScript (DOM manipulation, events, `localStorage`, `data-*` attributes)

## What I learned

- Building a mobile-first layout with Flexbox and media queries
- Using CSS variables to create a light and dark theme
- Manipulating the DOM with `querySelector`, `classList` and `textContent`
- Creating a translation system with a JavaScript object and `data-i18n` attributes
- Saving user preferences with `localStorage`
